## About the ticketing.
These tickets describe the requirements and tasks for creating the online calculator.

Each ticket starts with a number followed by a description. There is no strict format.

I do want to seperate the question from the tasks and details required to fulfill the ticket. My assumption is that this will give AI agents a faster index. So if we have a file 0002-database-setup.md, there can also be a 0002-database-setup_details.md

Steps in each ticket:
1: User describes each ticket
2: User asks ai to make the ticket totally clear (edit the ticket)
3: User optionionally asks ai to create the tasks and details document
4: User makes sure the ticket and details are complete
5: User asks ai to help implement the ticket.
6: Test
7: Mark ticket done and move ticket + any details to done.

Tasks paused for later are put in the backlog folder.
